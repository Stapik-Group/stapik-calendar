# Tastenkürzel und Mausaktionen

## Tastatur

- `←` `→` — voriger / nächster Tag
- `↑` `↓` — gleicher Wochentag in der vorigen / nächsten Woche
- `Bild auf` `Bild ab` — voriger / nächster Monat
- `Strg`+`Bild auf` `Strg`+`Bild ab` — voriges / nächstes Jahr
- `Pos1` oder `Strg`+`T` — zu heute springen
- `Eingabe` oder `Strg`+`N` — neuer Eintrag am ausgewählten Tag
- `Strg`+`1` `Strg`+`2` `Strg`+`3` — Monats- / Wochen- / Tagesansicht
- `Strg`+`Z` — Rückgängig
- `Strg`+`Umschalt`+`Z` — Wiederholen
- `Strg`+`Q` — Beenden
- `F1` — Diese Anleitung öffnen

## Maus

- Leere Stelle eines Tages, Doppelklick — neuer Eintrag
- Leere Stelle eines Tages, Rechtsklick — neuer Eintrag aus einer kopierten Webadresse
- Eintrag, Klick auf den Namen — Eintrag bearbeiten
- Link-Symbol ↗ am Eintrag, Klick — öffnet den Link
- Eintrag, Rechtsklick — Farbe wählen
- Eintrag, auf einen anderen Tag ziehen — verschieben
- Eintrag, `Strg` + auf einen anderen Tag ziehen — kopieren
- ✕ am Eintrag, Klick — Eintrag löschen
