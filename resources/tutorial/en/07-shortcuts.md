# Shortcuts and mouse actions

## Keyboard

- `←` `→` — previous / next day
- `↑` `↓` — same weekday in the previous / next week
- `Page Up` `Page Down` — previous / next month
- `Ctrl`+`Page Up` `Ctrl`+`Page Down` — previous / next year
- `Home` or `Ctrl`+`T` — go to today
- `Enter` or `Ctrl`+`N` — new entry on the selected day
- `Ctrl`+`Z` — Undo
- `Ctrl`+`Shift`+`Z` — Redo
- `Ctrl`+`Q` — Exit
- `F1` — Open this tutorial

## Mouse

- Empty area of a day, double-click — new entry
- Empty area of a day, right-click — new entry from a copied web address
- Entry, click on its name — edit the entry
- Link symbol ↗ on an entry, click — opens the link
- Entry, right-click — choose a color
- Entry, drag to another day — move it
- Entry, `Ctrl` + drag to another day — copy it
- ✕ on an entry, click — delete the entry
