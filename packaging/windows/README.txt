Stapik Calendar - test build for Windows
===================================================================
EN
--
Running
  1. Extract the WHOLE folder from the ZIP (do not run the program from inside the archive).
  2. Start stapikcalendar.exe. No installation is needed.

  On the first start Windows may show "Windows protected your PC" (SmartScreen) because the
  program is not signed. Click "More info", then "Run anyway".

Where the data is
  Calendar:    %APPDATA%\stapikcalendar\data\calendar.json
  Settings:    %APPDATA%\stapikcalendar\config
  Log:         %LOCALAPPDATA%\stapikcalendar\cache\stapik.log
  (paste these into the Explorer address bar). To back up, copy calendar.json.

Removing
  Delete the program folder and %APPDATA%\stapikcalendar (this also deletes the calendar).

Reporting problems
  Describe what you did and attach stapik.log and, if you can, a screenshot.

Language and theme: the Settings menu.
